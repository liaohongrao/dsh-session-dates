# dsh-session-dates · 会话按日期分组

给 DeepSeek Harness（dsh）侧边栏的「工作区 / 会话」区域加一层日期分组：**每个工作区里，会话按自然日分开，每一天写明具体日期**，而不是只给一个「3 天前」。

```
▾ deepseekharness                     12
    2026年10月28日 周三 · 今天          3
      ●  会话标题甲                    14:32
      ○  会话标题乙                    11:07
    2026年10月27日 周二 · 昨天          2
      ○  会话标题丙                    22:41
    2026年10月20日 周二 · 8天前         5
```

安装后它接管侧边栏的 `sidebar.workspaces` 槽位，保留「按工作区」的骨架，只在每个工作区内部按日期切段。

## 功能

- **日期分桶**：每个工作区内部按自然日分组，桶标题是硬日期（`2026年10月28日 周三`），右侧附「今天 / 昨天 / N 天前」。
- **当天内排序**：置顶会话在前，其余按时间倒序；同一行右侧显示 `HH:mm`。
- **运行状态**：会话正在运行时，行首圆点变成主题色并脉动；等待你输入是琥珀色，有新结果未读是绿色；有子代理在跑时显示子代理数量角标。
- **工作区折叠**：点标题折叠/展开，状态记在 localStorage。
- **搜索**：搜索框既按会话标题过滤，也接受日期查询——`2026-10-28`、`10-28`、`10月28日`、`今天`、`昨天`、`前天`、`本周`、`上周`。
- **归档**：默认隐藏已归档会话，右上「档」按钮切换为显示。
- **会话菜单**：每行 `⋯` 里保留原插件的会话操作（置顶、重命名、创建分支、归档、复制会话 ID），它们由原插件自己注册，本插件只是把它们渲染出来。
- **工作区操作**：`＋` 新建会话、`＋工作区` 选择目录新建工作区；工作区标题右键菜单可重命名 / 删除。

## 安装

装进某个 profile：

```sh
dsh plugin --profile <profile> add dsh-session-dates
```

或在应用内「插件」页的插件市场里安装（见 [PUBLISHING.md](./PUBLISHING.md)〔发布说明〕）。装好后刷新页面即可。

本地开发时也可以由插件管理器直接装目录：

```text
plugin_manager action=install_bundle target=/path/to/dsh-session-dates
```

## 兼容性与边界

- 只接管的浏览区域：`sidebar.workspaces` 及其子槽位（`sidebar.workspaces.session.menu.item`、`sidebar.workspaces.session.row.action`、`sidebar.session.row.leading`、`sidebar.workspaces.directoryFlow`）。会话操作、重命名弹窗、归档确认等仍由原插件提供。
- 不做拖拽排序，也不切换「平铺 / 工作区树」视图——日期分组是固定形态。手动排序请用原插件的「视图选项」。
- 搜索是本地过滤（标题 + 日期），不是引擎级全文检索。
- 刷新时先重新取一次会话状态；若某个子槽位渲染失败，行内会降级而不是整块白屏。
- 主题色、圆角、字色全部走 dsh 的 `--dsw-alias-*` 变量，深浅色主题自适应。
